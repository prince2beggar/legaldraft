# AIN-AI (আইন-AI) ব্যবহারকারী সহায়িকা ও সিস্টেম গাইড

এই নির্দেশিকাটি Windows PowerShell ব্যবহারকারীদের জন্য প্রণীত। অ্যাপ্লিকেশনটি স্থানীয় মেশিনে সঠিকভাবে চালু করা, ডেমো মোডে ব্রাউজ করা এবং সমস্ত স্ক্রিন যাচাই করার সম্পূর্ণ প্রক্রিয়া নিচে ধাপে ধাপে বর্ণিত হলো।

---

## ১. অ্যাপ্লিকেশন চালু করার প্রক্রিয়া (PowerShell Commands)

PowerShell চালু করে প্রকল্পের মূল ফোল্ডারে (`C:\legeldraft`) যান এবং নিচের নির্দেশাবলী অনুসরণ করুন:

### ক) ডেমো মোডে অ্যাপ্লিকেশন চালু (প্রস্তাবিত):
ডেমো মোডে অ্যাপ্লিকেশন চালু করলে একটি সম্পূর্ণ নিরাপদ ও পৃথক `demo.db` ডাটাবেস স্বয়ংক্রিয়ভাবে তৈরি হবে, যাতে বাস্তবসম্মত নমুনা মামলা, টাইমলাইন ও নোটিশ অন্তর্ভুক্ত থাকবে। **এটি কখনোই মূল `legal_saas.db` ডাটাবেস পরিবর্তন বা স্পর্শ করে না।**

```powershell
# টার্মিনালে রান করুন:
python run_app.py --demo
```

**টার্মিনালে যা দেখতে পাবেন:**
- সার্ভার ইউআরএল: `http://localhost:8000` বা `http://127.0.0.1:8000`
- ডাটাবেস পাথ: `C:\legeldraft\demo.db`
- বিল্ড স্ট্যাম্প: সংস্করণ, বিল্ড আইডি এবং শুরুর সময়
- ডেমো সতর্কতা ব্যানার সংক্রান্ত তথ্য

### খ) ডেভেলপমেন্ট / সাধারণ মোডে চালু:
```powershell
python run_app.py
```

## ২. ব্রাউজারে প্রবেশ ও সাইন-ইন প্রক্রিয়া

১. ব্রাউজার (Google Chrome / Edge) ওপেন করে প্রবেশ করুন:
   👉 **`http://localhost:8000/`**
২. রুট (`/`) ইউআরএল স্বয়ংক্রিয়ভাবে যাচাই করে যদি আপনি লগইন না থাকেন তবে আপনাকে **`/welcome`** (ওয়েলকাম ও সাইন-ইন পেজ)-এ নিয়ে যাবে।
৩. **লগইন তথ্য (ডেমো ব্যবহারকারী):**
   - **মোবাইল নম্বর:** `01711223344`
   - **'ওটিপি পাঠান'** বাটনে ক্লিক করুন।
   - **ডেমো ওটিপি:** স্ক্রিনে দৃশ্যমান ওটিপি (যেমন `123456`) প্রবেশ করিয়ে **'যাচাই করুন ও প্রবেশ করুন'** বাটনে ক্লিক করুন।
৪. ওটিপি যাচাই সফল হওয়ার সাথে সাথে ব্রাউজার আপনাকে স্বয়ংক্রিয়ভাবে **`/home`** (নাগরিক হোম ড্যাশবোর্ড)-এ নিয়ে যাবে।

## ৩. প্রতিটি স্ক্রিনে কী দেখতে পাবেন

### ১. হোম ড্যাশবোর্ড (`/home`)
- **শীর্ষ ব্যানার:** ডেমো মোডে থাকলে হলুদ রঙের সতর্কতা ব্যানার: `⚠️ ডেমো ডেটা — নমুনা (Demo Mode)` প্রদর্শিত হবে।
- **পরবর্তী পদক্ষেপ কার্ড (Next Action Card):** অগ্রাধিকারমূলক মামলা ও জরুরি সময়সীমার তাৎক্ষণিক অ্যাকশন গাইড।
- **জরুরি হটলাইন কার্ড:** জাতীয় আইনি সহায়তা (১৬৪৩০), জরুরি সেবা (৯৯৯) এবং নারী নির্যাতন প্রতিরোধ (১০৯) নম্বরসমূহ।
- **দ্রুত আইনি সেবা কার্ডসমূহ:**
  - 📁 নতুন মামলা তৈরি
  - ⚖️ আইনি মূল্যায়ন (Intake)
  - 📄 নোটিশ স্ক্যান ও আপলোড
  - 📝 আইনি খসড়া প্রণয়ন
  - 📚 আইন পাঠাগার

### ২. মামলা ফোল্ডার (`/cases`)
- ডেমো মোডে ২টি প্রস্তুতকৃত নমুনা মামলা দেখতে পাবেন (যেমন: চেক ডিজঅনার নোটিশ জবাব সংক্রান্ত মামলা)।
- যে কোনো মামলায় ক্লিক করলে **৮-ট্যাব বিশিষ্ট সম্পূর্ণ মামলা ওয়ার্কস্পেস (`/cases/{id}`)** ওপেন হবে:
  - সারসংক্ষেপ, টাইমলাইন, নথিপত্র, করণীয়, সময়সীমা, ব্যক্তিগত নোট, AI পর্যালোচনা এবং আইনজীবী শেয়ার।

### ৩. আইনজীবী ব্রিফ ও সম্মতি প্রদান (`/cases/{id}/lawyer` এবং `/me/sharing`)
- আইনজীবীর সাথে শেয়ার করার জন্য এক ক্লিকে কনফিডেনশিয়াল আইনি ব্রিফ তৈরি করা যায়।
- ডায়াগোনাল ওয়াটারমার্ক `[নমুনা - গোপনীয়]` সহ পিডিএফ/প্রিভিউ ও সম্মতি ব্যবস্থাপনার ড্যাশবোর্ড।

### ৪. আইনি খসড়া studio (`/draft`)
- বাংলাদেশ আইনানুগ অনুমোদিত টেমপ্লেট ক্যাটালগ (আইনি নোটিশ, ভাড়াচুক্তি ইত্যাদি)।
- প্রশ্নোত্তর উইজার্ড, স্বয়ংক্রিয় শর্তাবলী যাচাই এবং পিডিএফ ডাউনলোড।

### ৫. নথি আপলোড (`/documents/upload`)
- যেকোনো লিগ্যাল নোটিশ বা স্ক্যান কপি আপলোড ও স্বয়ংক্রিয় OCR প্রক্রিয়াকরণ।

### ৬. আইন পাঠাগার (`/library`)
- বাংলাদেশের সংবিধিবদ্ধ আইন ও নাগরিক আইনি অধিকারের সহজ ব্যাখ্যা এবং অনুচ্ছেদ অনুসন্ধান।

### ৭. বিজ্ঞপ্তি ও সেটিংস (`/notifications` এবং `/notification-settings`)
- মামলার ডেডলাইন অ্যালার্ট, নীরব সময় (Quiet Hours: 22:00 - 07:00) সেটিংস।

## ৪. কোন বিল্ড সংস্করণ দেখছেন তা যাচাই করার পদ্ধতি

১. **পেজ ফুটারে দেখুন:**
   প্রতিটি পেজের নিচে (Footer) একটি দৃশ্যমান বিল্ড স্ট্যাম্প ব্যাজ রয়েছে:
   `বিল্ড: v2.0.0 (3d87656) | মোড: demo`
২. **সরাসরি API কল করে দেখুন:**
   ব্রাউজারে প্রবেশ করুন:
   👉 **`http://localhost:8000/api/v1/build`**
   এটি নিরাপদ JSON আউটপুট প্রদান করবে:
   ```json
   {
     "version": "2.0.0",
     "build_id": "3d87656",
     "started_at": "2026-10-08T...",
     "mode": "demo"
   }
   ```
   *(এখানে কোনো গোপন ডাটাবেস পাথ বা সিক্রেট কী প্রকাশিত হয় না)*।

## ৫. সার্ভিস ওয়ার্কার ও ব্রাউজার ক্যাশ পরিষ্কার করার নিয়ম

যদি নতুন কোনো আপডেট দেওয়ার পর ব্রাউজারে পুরাতন পেজ দেখা যায়, তবে নিচের সহজ পদ্ধতিতে ক্যাশ পরিষ্কার করুন:

### ব্রাউজার ডেভেলপার টুলস ব্যবহার করে:
১. কীবোর্ডে `F12` অথবা `Ctrl + Shift + I` চাপুন।
২. **Application** ট্যাবে যান (না পেলে `>>` চিহ্নে ক্লিক করুন)।
3. বাম পাশের মেনু থেকে **Service Workers**-এ ক্লিক করুন।
৪. **Unregister** বাটনে ক্লিক করুন।
৫. একই মেনুতে **Storage**-এ ক্লিক করে **Clear site data** বাটনে ক্লিক করুন।
৬. ব্রাউজারে `Ctrl + F5` চেপে হার্ড-রিফ্রেশ (Hard Refresh) করুন।

নতুন সার্ভিস ওয়ার্কার স্বয়ংক্রিয়ভাবে বিল্ড স্ট্যাম্পের সাথে মিলিয়ে নতুন ক্যাশ তৈরি করবে।
